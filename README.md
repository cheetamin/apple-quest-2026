# 애플왕의 진화 모험 — English Quest

**풋애플 → 애플왕 → 애플대왕**을 키우는 모바일 영어 학습 게임입니다.

## 교재(코스)
- 로그인 후 처음 한 번 교재를 고릅니다: 3학년 · 4학년 · 5학년 · 6학년 · 천재(이) 4학년.
- 3~6학년은 2022 개정 영어과 교육과정 기본 어휘(초등 *표시 800단어)를 바탕으로 만든 단원입니다 (`src/courses.js`).
- 천재(이) 4학년은 교과서 학습지 단어·문장 + 응용 문장입니다 (`src/data.js`).
- 나의 성장 화면이나 단원 선택 화면에서 언제든 교재를 바꿀 수 있고, 진도는 교재마다 따로 기록됩니다.

## 성장 규칙 (규칙 버전 2)
- 진화: 애플왕 = 경험치 300 · 단원 5개 · 1차 보스전 · 공부한 날 5일 / 애플대왕 = 경험치 900 · 단원 10개 · 2차 보스전 · 공부한 날 15일
- 퇴화: 학교 가는 날(월~금) 하루라도 공부를 빠지면 한 단계 전 모습으로, 7일 빠지면 풋애플로. 복습 퀴즈를 통과하면 바로 원래 모습으로 돌아옴. 기록·카드·아이템은 지워지지 않음.
- 🍎 사과: 새로 맞힌 문제 1 · 세트 통과 3 · 단원 완료 10 · 오늘 첫 공부 5 · 복습 통과 3 · 보스전 승리 20(재도전 5)
- 꾸미기 상점(`src/shop.js`): 얼굴·목·등·손·머리 장식·빛 효과 19가지. 일부는 애플왕/애플대왕으로 진화해야 열림.

## 애플 마을 (`src/village.js`)
- 🍽️ 먹이 주기: 배부름은 평일마다 20씩 줄어요(주말 제외). 사과로 먹이(5가지)를 사서 주면 배부름·애정도가 오르고, 배부름 50 이상이면 세트 통과 때 사과 +2.
- 🏠 내 집: 빈 땅 → 텐트 → 오두막 → 사과 지붕 집 → 2층 집 → 애플 궁전 (사과 + 공부한 날 + 진화 단계 필요)
- 🏘️ 마을: 단원을 마칠 때마다 건물 자리가 열리고 사과로 11가지 건물을 지음. 건물이 늘면 이웃 사과 친구들이 이사 옴.

- 가격(2026-11 조정): 꾸미기 아이템 60~1200🍎(약 3배), 집 60~1000🍎, 마을 건물 80~440🍎(2배). 먹이 값은 그대로.

## 파닉스 (`src/phonics.js`)
- 단원 선택 맨 위 "0. 파닉스 표": 알파벳 소리 26 · 긴 모음 10 · 짝꿍 글자 12. 글자를 누르면 소리(브라우저 영어 음성: 글자 이름 + 예시 단어), 소리 표기, 입 모양 그림(9가지)과 따라 하기 팁.
- 모든 단원 세트에 파닉스 1문제 추가(세트당 6문제): 단원 단어의 첫소리 글자 고르기. 같은 소리가 나는 글자(c/k/q, f/ph, w/wh 등)는 보기에 함께 나오지 않음. 세트 통과 기준은 문제 수에 맞춰 비율로(6문제 중 4개).

## 공모전 체험판 (`docs/contest/`)
- 주소: https://cheetamin.github.io/apple-quest-2026/contest/ — `python3 build.py`가 같은 코드로 함께 만듦(`window.AQ_CONTEST=true`).
- 학급 서버를 전혀 쓰지 않음(로그인 없이 이름만 정하면 시작, 기록은 그 기기에만 · 저장 키도 `aq-contest-v1`로 분리). 선생님 탭·제작자 관리실 대신 "체험 도우미"(사과 +1000, 단원 모두 완료, 진화, 배고픔·퇴화 상태 만들기, 초기화).
- 출판사 교과서 기반 '천재(이) 4학년' 교재는 빠짐.
