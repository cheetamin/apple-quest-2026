# 애플왕의 진화 모험 — English Quest

초등학교 3~6학년 영어(교육과정 권장 어휘 학년별 11단원 + 천재(이) 4학년 교과서) 단어와 문장을 공부하며 학급 마스코트
**풋애플 → 애플왕 → 애플대왕**을 키우는 모바일 영어 학습 게임입니다.

## 바로 하기
👉 **https://rkdrkals0227.github.io/apple-quest-2026/**

계정·설치 없이 휴대폰이나 컴퓨터 브라우저에서 바로 할 수 있어요 (세로 9:16 화면).

## 들어 있는 것
- 게임 시작 화면 → 인트로 영상(SKIP 가능) → 이름 정하기 → 홈
- 홀로그램 캐릭터 카드 + 영어 퀴즈 (그림·뜻·듣기·문장 듣기·빈칸·순서 배열·짝 맞추기)
- 교과서 단어·문장 + 문형 응용 문장 약 120개
- 경험치·3단계 진화·진화 연출·도감·복습 보스전(3·6·11단원)·사과숲 꾸미기
- 미접속 퇴화(주말 일시정지, 복습으로 복구)
- 나가기 → 하트 5개 만족도 조사 → 감사 인사, 제작자 관리실(설정 → 나의 성장)

## 저장 방식
- 학급 서버(Cloudflare) 연결 후: 학교·학년·반·번호·닉네임·비밀번호 4자리로 **어느 기기에서든** 이어서 해요. 선생님 탭에서 우리 반 현황과 구글 시트 연결을 쓸 수 있어요. 설정 방법은 [`SETUP.md`](SETUP.md).
- 연결 전: 기록은 각 기기의 브라우저에 저장돼요.

## 수정하고 다시 만들기
```
python3 build.py          # src/ + assets/ → docs/index.html
node --test tests/logic.test.js tests/server.test.mjs
```
`docs/` 폴더가 GitHub Pages로 공개되는 파일입니다. 자세한 구조는 `CLAUDE.md` 참고.

## 교재(코스)
- 로그인 후 처음 한 번 교재를 고릅니다: 3학년 · 4학년 · 5학년 · 6학년 · 천재(이) 4학년.
- 3~6학년은 2022 개정 영어과 교육과정 기본 어휘(초등 *표시 800단어)를 바탕으로 만든 단원입니다 (`src/courses.js`).
- 천재(이) 4학년은 교과서 학습지 단어·문장 + 응용 문장입니다 (`src/data.js`).
- 나의 성장 화면이나 단원 선택 화면에서 언제든 교재를 바꿀 수 있고, 진도는 교재마다 따로 기록됩니다.
