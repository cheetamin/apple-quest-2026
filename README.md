# 애플왕의 진화 모험 — English Quest

초등학교 4학년 영어(1·2학기, 11단원) 단어와 문장을 공부하며 학급 마스코트
**풋애플 → 애플왕 → 애플대왕**을 키우는 모바일 영어 학습 게임입니다.

## 바로 하기
GitHub Pages 주소로 접속하면 계정·설치 없이 바로 할 수 있어요 (휴대폰 세로 화면 9:16 기준).

## 들어 있는 것
- 게임 시작 화면 → 인트로 영상(SKIP 가능) → 이름 정하기 → 홈
- 홀로그램 캐릭터 카드 + 영어 퀴즈 (그림·뜻·듣기·문장 듣기·빈칸·순서 배열·짝 맞추기)
- 교과서 단어·문장 + 문형 응용 문장 약 120개
- 경험치·3단계 진화·진화 연출·도감·복습 보스전(3·6·11단원)·사과숲 꾸미기
- 미접속 퇴화(주말 일시정지, 복습으로 복구), 선생님 관리실(처음 비밀번호 1234)

## 저장 방식
학습 기록은 **각 기기의 브라우저**에 저장됩니다. 기기를 바꾸거나 브라우저 기록을 지우면 처음부터 시작해요.
학급 서버 저장(학급 코드·학생 계정·반 전체 현황)은 다음 개발 단계입니다.

## 수정하고 다시 만들기
```
python3 build.py          # src/ + assets/ → docs/index.html
node --test tests/logic.test.js
```
