# 🍡 11월 11일 가래떡 모션 게임

> 움직이고, 생각하고, 함께 배우는 학급 대항전!

농업인의 날(11월 11일)을 맞아 초등학교 1~6학년이 교실 전자칠판에서 즐기는 **체감형 교육 게임**입니다.
**전자칠판 카메라 1대**로 두 학생(청팀·백팀)의 몸 움직임을 동시에 인식하고, 신체 게임과 교과 복습 퀴즈를 번갈아 진행하는 12라운드 학급 대항전입니다.

- 설치·로그인·유료 서비스 없음 — 웹 브라우저(Chrome/Edge)만 있으면 됩니다.
- 카메라 영상은 **이 기기 안에서만** 처리됩니다(외부 전송·저장 없음).
- 모든 캐릭터·배경·음악·효과음은 이 프로젝트에서 직접 만든 오리지널입니다.

## 1. 빠르게 시작하기

### 방법 A — GitHub Pages로 배포 (무료, 권장)
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다(`index.html`이 최상위에 오도록).
2. 저장소 **Settings → Pages → Build and deployment**에서 *Source: Deploy from a branch*, *Branch: main / (root)* 를 선택하고 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 생깁니다. 전자칠판 브라우저에서 이 주소를 열면 됩니다.

### 방법 B — Netlify Drop (가입 후 끌어다 놓기)
`https://app.netlify.com/drop` 에 이 폴더를 끌어다 놓으면 https 주소가 바로 만들어집니다.

### 방법 C — 내 컴퓨터에서 실행 (개발·점검용)
```bash
cd garaetteok-motion-game
python -m http.server 8080        # 또는: npx serve .
# 브라우저에서 http://localhost:8080 접속
```
> ⚠️ `index.html`을 더블클릭(file://)하면 동작하지 않습니다. 카메라는 **https 주소 또는 localhost**에서만 켜집니다(브라우저 보안 규칙).

### 카메라 없이 미리 보기
주소 끝에 `?sim=1`을 붙이면(예: `http://localhost:8080/?sim=1`) **가상 학생 2명**으로 전체 게임을 점검할 수 있습니다. 카메라 화면에서 **[🧪 시뮬레이션 점검]** 버튼을 눌러도 됩니다.

## 2. 게임 구성 (학생 수에 맞춘 라운드)

기본은 **학생 수 맞춤 모드**예요. 반 전체 인원의 절반(홀수면 올림)만큼 일반 라운드가 생기고, 라운드마다 팀별 1명씩 나와 모두 한 번씩 출전해요. 인원이 적은 팀은 앞 순서 학생이 한 번 더 나가요. 11라운드보다 많으면 교과 퀴즈·신체 게임이 "2탄"으로 번갈아 추가되고, 적으면 신체·두뇌가 번갈아 나오도록 골라요. 마지막은 항상 전원 참여 이어달리기예요. (설정에서 '12라운드 고정(대표 선수)'도 고를 수 있어요.)

아래는 11라운드 + 결승의 기본 구성이에요.

| # | 라운드 | 구분 | 입력 |
|---|---|---|---|
| 1 | 가래떡 썰기 대회 | 신체 | 팔 올렸다 내리기(완전한 1회 = 1번 썰기) |
| 2 | 가래떡 연산 대회 | 두뇌·수학 | 팀별 숫자 입력판(교사 설정 시 모션 선택) |
| 3 | 가래떡 날기 대회 | 신체 | 두 팔 날갯짓(위→아래) 횟수로 구름 위까지 날아오르기 |
| 4 | 가래떡 맞춤법 대회 | 두뇌·국어 | 팀별 10문제 스피드 레이스(문제·번호 순서가 팀마다 달라 컨닝 불가) |
| 5 | 청가래떡 백가래떡 대회 | 신체 | 실제 몸 기준 왼팔(청)·오른팔(백) |
| 6 | 가래떡 사회 탐험 대회 | 두뇌·사회(1~2학년 통합교과) | 팀별 터치 객관식 |
| 7 | 가래떡 댄스 대회 〈떡떡! 가래떡 댄스〉 | 신체 | 정해진 동작 정확도 + 박자 |
| 8 | 가래떡 과학 탐구 대회 | 두뇌·과학(1~2학년 통합교과) | 팀별 터치 객관식 |
| 9 | 날아오는 가래떡 피하기 | 신체 | 몸통 중심 좌우 이동(3차선) |
| 10 | 가래떡 영단어 대회 | 두뇌·영어(1~2학년 맛보기) | 팀별 터치 객관식 + 영어 음성 |
| 11 | 몸으로 말해요! 가래떡 OX | 혼합 | O=양팔 위, X=양팔 교차(1초 유지) |
| 12 | 가래떡 이어달리기 결승전 | 전원 참여 | 제자리 달리기(무릎·팔 교대 동작) |

- 교과 퀴즈(4·6·8·10라운드): 정답 1개 7점 + 10문제를 끝까지 풀고 정확도 70% 이상일 때만 빨리 끝낼수록 속도 보너스 최대 30점. 서두르다 4개 이상 틀리면 보너스 실패.
- 댄스·이어달리기 음악: 사용자가 Suno로 만든 〈가래떡 댄스〉(`assets/audio/dance.mp3`). 곡의 실제 박자 231개를 분석한 `dance.beats.json`으로 동작 판정을 맞춤. 노래방 자막 타이밍은 교사용 [🎤 댄스 가사 타이밍 맞추기]로 만들어요. 음원 파일이 없으면 내장 합성 노래로 자동 대체.
- 1~11라운드는 **팀별 100점 만점**(합계 최대 1,100점). 경기를 여러 번 하면 평균을 내서 100점 만점을 유지합니다.
- 결승 이어달리기: 두 팀 모두 **같은 구간 수(큰 팀 인원)**를 달립니다. 앞선 점수 차 × 0.03%만큼(최대 트랙의 10%) 앞에서 출발하고, **결승선을 먼저 통과한 팀이 우승**합니다.

교사용 설명서: [`docs/TEACHER_GUIDE.md`](docs/TEACHER_GUIDE.md)

## 3. 카메라 1대로 두 학생을 인식하는 방식

```
카메라 1대 ─▶ MediaPipe Pose Landmarker (numPoses: 2, 브라우저 안에서 실행)
          ─▶ 2인 추적기 TwoPersonTracker (js/core/tracker.js)
               · 처음: 두 사람이 떨어져 서면 화면 왼쪽=청팀, 오른쪽=백팀으로 보정
               · 이후: 위치 연속성 + 몸 크기 + 체형 비율(관절 길이 비율)로 팀 유지
                       → 화면을 반으로 자르지 않음. 가운데 점선은 안내용
               · 겹침 감지 → 두 팀 채점 일시정지, 분리 후 체형 비율로 재확인
               · 한 명 안 보임 → 그 팀만 채점 정지 / 둘 다 안 보임 → 게임 일시정지
          ─▶ 신체 신호 bodySignals (js/core/body.js)
               · 모든 기준을 몸통 길이·어깨너비로 정규화 → 키·체격 차이 자동 보정
               · 왼팔/오른팔은 관절 라벨(실제 몸 기준)로 판정 → 거울 모드와 무관
          ─▶ 라운드별 판정기 (js/core/gestures.js, js/rounds/*.js)
```
- 얼굴이나 외모는 평가하지 않습니다. 관절의 상대 위치와 움직임만 사용합니다.
- 인식된 시간만큼만 목표치를 계산하므로, 카메라 인식 실패로 점수를 잃지 않습니다.
- 2인 인식이 안 되거나 느린 환경에서는 오류를 숨기지 않고 원인과 해결 방법을 화면에 표시합니다.

## 6. 바꾸고 싶을 때
- **음원 교체**: `assets/audio/`에 파일을 넣고 `js/config.js`의 `audioFiles`에 경로를 적습니다. 댄스 음원을 바꾸면 `danceBpm`도 맞춰 주세요.
- **문제 추가·수정**: 게임 안 **교사용 설정 → 📚 문제 관리**(브라우저에 저장, JSON 내보내기/가져오기) 또는 `js/data/bank.js` 직접 편집.
- **인터넷 없이 사용**: [`docs/OFFLINE.md`](docs/OFFLINE.md)
