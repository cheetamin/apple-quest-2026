# 🧑‍🏫 교사용 간단 사용 설명서

## 준비물
- 카메라가 달린 전자칠판(또는 PC + 웹캠 1대)
- Chrome 또는 Edge 최신 버전
- 게임 주소(https:// 로 시작하는 GitHub Pages 주소 등)

## 교실 배치 (가장 중요해요)
```
            [ 전자칠판 / 카메라 ]
                   │  2~3m
     ┌─────────────┼─────────────┐
     │  청팀 자리   ┆   백팀 자리  │   ← 두 학생 사이 1.5m 이상(두 팔을 벌려도 닿지 않게)
     │ (화면 왼쪽)  ┆ (화면 오른쪽)│
     └─────────────┴─────────────┘
         나머지 학생은 카메라에 들어오지 않도록 뒤쪽·옆쪽에서 응원
```
- 카메라에 **머리부터 무릎(가능하면 발목)까지** 보이게 서요. 이어달리기는 무릎이 보일수록 정확해요.
- 창문 역광을 피하고 교실 조명을 켜요. 카메라 화면의 [조명·화질] 항목이 안내해 줘요.
- 카메라 앞에는 **두 명만** 서요. 세 번째 사람이 들어오면 인식이 흔들릴 수 있어요(카메라 모델은 최대 2명을 찾아요).

## 진행 순서
1. **시작하기 → 교사용 설정**: 학년·학기, 팀 이름, 팀별 학생 수(1~60명), 학생 이름(선택), 라운드 시간(45/60/90초), 릴레이 1인 시간(10/15/20초), 참여 방식을 정해요.
   - *학생 수에 맞춰 라운드(추천)*: 반 인원의 절반만큼 일반 라운드가 생겨요(예: 24명 → 12라운드, 25명 → 13라운드). 라운드마다 팀별 1명씩 나와 모두 한 번씩 출전하고, 홀수면 한 명이 한 번 더 나가요. 마지막은 전원 이어달리기.
   - *12라운드 고정(대표 선수)*: 1~11라운드는 팀별 대표 1명, 결승 릴레이는 전원.
   - 설정 화면에 라운드 목록과 예상 시간이 바로 나오고, [📋 출전표 보기]로 학생별 출전 라운드를 확인할 수 있어요.
2. **카메라 연결 및 2인 보정**: [📷 카메라 1대 연결] → 브라우저 권한 "허용" → 두 학생이 좌우로 서면 체크 항목이 ✅로 바뀌고 [시작하기]가 켜져요.
   - [🙋 좌우 팔 확인]: 두 학생이 왼팔을 들면, 카메라가 좌우 반전 영상을 보내는 경우 자동으로 바로잡아요.
3. **라운드 안내** 화면에서 방법·점수·안전 수칙·출전 학생을 확인하고 [준비 완료!] → 3초 카운트다운 후 시작.
4. **라운드 결과**에서 점수와 칭찬을 확인하고 [다음 ▶].
5. **결승 이어달리기**: 주자가 바뀔 때마다 "바통 터치!" 화면이 나오고, 두 주자가 인식되면 자동으로 출발해요.
6. **시상식**: 우승팀 발표, 팀별 칭찬, 라운드별 기록. [💾 결과 저장(CSV)]으로 파일을 저장할 수 있어요.

## 두뇌 게임(퀴즈) — 팀별 10문제 스피드 레이스
- 두 팀이 **같은 10문제를 서로 다른 순서와 다른 번호 배열**로 각자 풀어요. 옆 팀 화면을 봐도 도움이 안 돼요.
- 정답 1개 7점. 10문제를 끝까지 풀고 **정확도 70% 이상**이면 빨리 끝낼수록 속도 보너스(최대 30점). 서두르다 4개 이상 틀리면 보너스 실패! 틀리면 정답과 해설이 잠깐 나온 뒤 다음 문제로 넘어가요.

## 두뇌 게임(퀴즈) 입력 방법
- 화면 아래 **왼쪽 = 청팀, 오른쪽 = 백팀** 전용 버튼이에요. 두 팀의 번호 순서는 서로 달라서 상대 번호를 따라 누를 수 없어요.
- 번호를 누르면 강조 → **[✔ 확정]**을 눌러야 답이 기록돼요. 확정 전에는 다른 번호로 바꿀 수 있어요.
- 동시 터치가 안 되는 전자칠판이어도 두 팀이 차례로 누르면 각각 따로 기록돼요.
- 정답 공개 후 교사가 [교사: 정답 인정]을 눌러 수동으로 정답 처리할 수 있어요.

## 🎵 댄스 노래와 가사 자막
- 7라운드 댄스와 12라운드 이어달리기에서 〈가래떡 댄스〉 노래(`assets/audio/dance.mp3`)가 나와요. 동작 판정은 이 노래의 실제 박자에 맞춰져 있어요.
- **노래방 자막 맞추기(처음 한 번, 약 2분)**: 교사용 설정 → [🎤 댄스 가사 타이밍 맞추기] → [▶ 처음부터 재생] → 노래에서 각 줄이 시작될 때 **스페이스 키**(또는 큰 버튼) → [저장]. 이 컴퓨터에 저장되어 댄스 화면에 줄마다 가사가 나와요. 맞추기 전에는 후렴 가사 6줄이 한꺼번에 표시돼요.
- 다른 컴퓨터에도 똑같이 쓰려면 저장 후 나오는 내용을 `js/config.js`의 `danceLyrics`에 붙여 넣어 배포해요.
- 노래를 바꾸려면 `assets/audio/dance.mp3`를 교체하고 박자 파일(`dance.beats.json`)도 다시 만들어야 해요.

## 교사 관리 메뉴 (ESC 키 또는 화면 구석 ⚙ 버튼)
| 기능 | 설명 |
|---|---|
| ▶ 계속하기 / 일시정지 | 메뉴를 열면 게임이 멈추고, 닫으면 이어져요 |
| 🔁 라운드 다시 시작 | 현재 경기를 처음부터 다시 |
| ⏭ 라운드 건너뛰기 | 두 팀 모두 0점으로 기록(유불리 없음) |
| 👥 학생 교대 | 현재 경기 출전 학생 변경(미출전 학생이 먼저 보여요) |
| ✏️ 점수 수동 수정 | 모든 라운드 점수를 0~100점으로 직접 수정 |
| 🩺 모션 인식 상태·보정 | 인식 속도·인원·신뢰도 확인, 2인 다시 보정, 거울 모드, 민감도, 대체 입력 켜기 |
| 🔊 음량 | 전체·배경음악·효과음 따로 조절, 전체 음소거 |
| ⛶ 전체 화면 | 전자칠판 전체 화면 |
| 🧹 게임 초기화 | 확인 후 처음 화면으로 |

진행 중인 경기는 자동 저장돼요. 실수로 창을 닫아도 처음 화면의 **[▶ 이어하기]**로 이어서 할 수 있어요.

## 운동이 어려운 학생 / 카메라 문제가 있을 때 (대체 입력)
- 설정 또는 🩺 메뉴에서 **신체 활동 대체 입력**을 해당 팀(또는 양 팀)으로 켜면, 신체 라운드 옆 칸에 버튼이 생겨요. 교사나 학생이 버튼을 눌러 동작을 대신해요.
- 키보드로도 가능해요 — 청팀: Q 왼팔 · W 오른팔 · E 양팔 위(O) · R 교차(X) · T 양팔 벌리기 · A/D 좌우 이동 · S 동작(썰기·내려놓기·달리기) / 백팀: U · I · O · P · Y · J/L · K
- **앉아서 참여 모드**: 피하기는 몸 기울이기, 이어달리기는 팔 흔들기로 판정해요.
- **느린 속도 모드**, **글자 크게**, **고대비 화면**, **문제 읽어주기**를 설정에서 켤 수 있어요.

## 안전 수칙
- 과격한 점프, 깊게 앉기, 회전, 친구 쪽으로 팔 뻗기를 요구하지 않아요.
- 이어달리기는 **제자리**에서만 달리고, 교대할 때는 걸어서 자리를 바꿔요. 한 구간에서 갈 수 있는 거리에 상한이 있어서 무리하게 빨리 뛸 필요가 없어요.
- 학생이 카메라나 전자칠판에 너무 가까이 다가가지 않도록 바닥에 테이프로 자리를 표시해 두면 좋아요.

## 자주 묻는 질문
- **카메라가 안 켜져요** → 주소가 https인지 확인 / 주소창 왼쪽 자물쇠에서 카메라 "허용" / 화상회의 프로그램 종료.
- **"자세 인식 모델을 불러오지 못했어요"** → 처음 실행할 때 인터넷이 필요해요(모델 약 5~10MB). 학교 방화벽이 막는다면 `docs/OFFLINE.md` 방법으로 파일을 함께 배포하세요.
- **인식이 느려요(10fps 미만)** → 설정에서 자세 인식 모델을 "빠름(lite)"으로, 다른 프로그램 종료.
- **팀이 뒤바뀌어 보여요** → 두 학생을 좌우로 떨어뜨린 뒤 🩺 메뉴의 [2인 다시 보정].
- **왼팔/오른팔이 반대로 판정돼요** → 카메라 화면의 [좌우 팔 확인] 또는 🩺 메뉴의 "좌우 판정 반전".

## 개인정보
- 카메라 영상·사진은 저장하거나 외부로 보내지 않아요(브라우저 안에서만 처리).
- 학생 이름 입력은 선택이며, 경기 기록에는 학생 이름을 저장하지 않아요(학년·팀 이름·인원·점수·우승팀·경기 시간만).
- 기록은 이 컴퓨터 브라우저에만 보관돼요. [기록 보기]에서 지울 수 있어요.

## 카메라가 안 될 때

카메라 연결 화면에서 문제가 생기면 화면 가운데에 **해결 순서**가 나와요. 그래도 안 되면 **[📋 진단 정보 복사]**를 눌러 제작자에게 보내 주세요.

| 증상 | 확인할 것 |
|---|---|
| "카메라 사용이 막혀 있어요" | 주소창 자물쇠 › 사이트 설정 › 카메라 **허용** / 윈도우 설정 › 개인 정보 및 보안 › 카메라 › **데스크톱 앱이 카메라에 액세스하도록 허용** 켜기 |
| "카메라를 켤 수 없어요" | 전자칠판 카메라 앱·줌·다른 크롬 탭 닫기 → 크롬 완전히 껐다 켜기 |
| "카메라를 찾지 못했어요" | 전자칠판 **연결 PC(윈도우)의 크롬**에서 열었는지(전자칠판 내장 안드로이드 화면 X), 카메라 덮개·USB |
| 화면이 검게 나와요 | 카메라 덮개 / 목록에서 **다른 카메라** 선택(얼굴 인식용 IR 카메라는 안 돼요) |
| 화면은 나오는데 사람을 못 찾아요 | 2~3m 떨어져 머리~무릎까지 보이게, 조명 켜기, 창문 역광 피하기 |
| "자세 인식 모델을 불러오지 못했어요" | 새로고침 후 다시 연결(처음엔 30초 이상 걸릴 수 있음), 다른 인터넷(핫스팟)으로 시험 |

- 게임은 **이전에 고른 카메라를 기억**하고, 그 카메라가 안 되면 다른 카메라와 낮은 해상도로 **자동 재시도**해요.
- 자세 인식 파일은 게임 사이트에 함께 올려 두어서, 학교망에서 외부 사이트가 막혀 있어도 동작해요.
- 끝내 카메라를 쓸 수 없으면 **[🖐 카메라 없이 진행]**으로 교사가 화면 버튼으로 대신 입력해 수업을 이어갈 수 있어요.
